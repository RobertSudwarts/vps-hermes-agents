# Bounded role assessment

Use this reference only for a requested new-role pass, substantive reassessment, or expansion beyond the saved pipeline.

1. State the search scope, date, sources and a maximum number of roles for substantive review.
2. Collect and deduplicate mechanically. Retain exact posting URLs or requisition IDs.
3. Apply inexpensive exclusions first: closed listing, incompatible location, explicitly mandatory German, or clearly role-defining unsupported requirements.
4. For each remaining role, read the primary advert and compare its actual work with supported career evidence. Separate direct evidence, transferable evidence and genuine gaps.
5. Stop at the declared cap. Report unreviewed roles as pending rather than quietly expanding the pass.
6. Save the observation, evidence, decision and reason in the existing register. Do not call unseen backlog newly published.

Use `grounded-citations` when external facts or an ambiguous advert need evidence beyond the primary posting.
