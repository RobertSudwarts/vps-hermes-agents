# CV follow-ups

Use for a scoped edit to an existing draft or for recording a reported submission.

For an edit, read the affected passage and make only the authorised change in `working/cv.md`. Preserve unrelated wording and show the changed passage. Do not reread the entire career record, rebuild a PDF or run fresh employer research unless the request requires it.

For a user-reported submission, preserve the delivered documents and update the existing application and opportunity records together. Do not infer employer receipt, final pasted form answers or outgoing attachment bytes without evidence. Run the existing archive verifier once after the complete transaction.
