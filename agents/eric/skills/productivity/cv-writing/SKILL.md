# CV writing

Use this skill for a named role, focused open application, substantive CV rewrite, or a scoped edit to an existing CV draft.

## Stage 1 only: Markdown for review

Create or revise `Applications/YYYYMMDD/<application>/working/cv.md`. This is the editable editorial source of truth for that application.

Do not generate a PDF, alter the shared template, or create a submission record unless Rob explicitly asks for that separate action. A request to build a PDF after approval routes to `career-pdf`.

## Evidence and authority

Use the role specification, the protected factual record under `/vault/eric/CV/`, and confirmed supplements. Do not modify protected source material while tailoring. New truthful prose, synthesis, reordering and shortening are allowed; invented achievements, scope, qualifications, proficiency, dates, titles and outcomes are not.

Load the smallest applicable reference:

- A new role or substantive rewrite: `references/substantive-cv.md` and `references/review-checklist.md`.
- A scoped wording/skills edit or a user-reported submission: `references/follow-ups.md`.
- Application-form answers: `references/application-form-answers.md`.

`job-discovery` owns vacancy discovery. `grounded-citations` verifies employer or vacancy claims. `cover-letter-writing` owns letters.

## Deliverable

Show the Markdown draft or the requested changed passage. State any factual question that genuinely blocks a supported claim. Do not ask for approval merely to restate known evidence.
