# Cover-letter writing

Use for a cover letter, motivation letter or application statement for a named role or a focused open application. It explains mutual fit; it is not a CV rewritten as paragraphs.

Start with the exact role, relevant career evidence, and existing verified employer context. The factual record, not a previously delivered CV, is authoritative. Do not modify protected source material. Retrieve fresh employer facts only when a new/current factual claim requires them; use `grounded-citations` where needed.

Keep the letter separate from CV drafting. A letter request does not authorise a CV rewrite, application, outreach or external upload. When both documents are requested, reuse the same evidence without duplicating the full career narrative.

For a new or substantially revised letter, follow [the drafting method](references/letter-method.md). Save the Markdown draft and brief private evidence/editorial notes in the chosen application's `working/` directory. Show it for Rob's review unless he explicitly requests a ready document.

Only after Rob explicitly approves the wording *and* asks for a PDF, follow [the letter PDF procedure](references/letter-pdf.md). It is intentionally separate from `career-pdf`, which builds CVs only. Freeze the approved letter text; production may change presentation, never wording.
